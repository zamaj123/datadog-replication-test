# PRODUCT.md

## Product
Build a substantial observability platform inspired by Datadog.

## Core capabilities
- Metrics ingestion and querying
- Log ingestion and querying
- Trace ingestion and querying
- Correlation across metrics, logs, and traces
- Dashboards
- Alerting
- Multi-service/system visibility
- Search and drilldown UX

## Initial target
The platform must support a Dockerized Node.js application first, but architecture should allow expansion to more runtimes and services.

## Product standard
This is not a toy prototype. Work should optimize for extensibility, coherent architecture, and integration across subsystems.
